# This is a House Gallery — Astro frontend

This is the Astro static frontend for [thisisahousegallery.com](https://thisisahousegallery.com),
an upgrade from the previous Wagtail-based implementation.

It lives under `www/` in the `thisisahousegallery` repository.

## Getting started

```bash
npm install
npm run dev      # development server
npm run build    # production build (outputs to dist/)
npm run preview  # preview the production build
```

## Structure

- `src/pages/` — Astro routes
- `src/layouts/` — shared layout components
- `src/styles/` — global styles and design tokens
- `public/` — static assets (fonts, images)
